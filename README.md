# ai-assisted-development-workflow

How a product development team should work when large language models write the code: roles, team shape and the flow from task to reviewed code.

- [dev-org.md](dev-org.md) describes the organization and the scaffolding-first development process.
- [workflow.svg](workflow.svg) shows the flow as a diagram. It is a draw.io export with the diagram embedded, so it can be opened and edited in draw.io.

Which stack suits this way of working is covered in [ai-assisted-development-stack](https://github.com/Schinzel/ai-assisted-development-stack).

This repo replaces the older [ai-assisted-development](https://github.com/Schinzel/ai-assisted-development), which is archived.
